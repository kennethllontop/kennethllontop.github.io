Part A

Image Warping and Mosaicing

In Part A, we are exploring image warping and mosaics. I decided to capture my freshman and senior year dorm experience by taking pictures of Foothill. I fixed the center of projection, rotated my camera between shots, and stitched the pictures into a mosaic. In order to create the mosaic, I had to find corresponding points, recover the homography between the two images, warp one image into the other’s frame with inverse warping, and finally blend them together. I wrote the homography solver, both interpolation methods, and the blending myself, without using the built-in homography or warping functions from OpenCV or scikit-image.

Homography

Least Squares

21 hand-clicked correspondences per pair give an overdetermined system for the 8 unknowns.

Warping

Inverse, Bilinear

Each output pixel is mapped back through H−1 and sampled from the source image.

Blending

Weighted Average

Each image is weighted by its distance to its own border, so seams fade out.

Recovering Homographies

A homography maps a point p = (x, y, 1) in one image to p′ = Hp in the other, up to a scale w. Fixing the bottom-right entry to 1 leaves 8 unknowns. Dividing out w and moving everything to one side turns each correspondence into two linear equations in those unknowns.

[wx′wy′w]=[h11h12h13h21h22h23h31h321][xy1] [xy1000−xx′−yx′000xy1−xy′−yy′]h=[x′y′] h=[h11h12h13h21h22h23h31h32]T

With exactly 4 points, the system has a unique solution, but a couple of pixels of clicking error can throw it off. So for the mosaics I clicked 21 points per pair and solved the stacked 42×8 system with least squares. The result is the homography that maps image 1 points onto image 2 points.

Part A · 3

Warping the Images

To warp an image, I first send its four corners through H and find the bounding box of the output. Then, for every pixel in this box, I apply H−1 to find where it came from in the source image. Going backwards like this means every output pixel gets a value, so there are no holes. I treat integer coordinates as pixel centers, so the valid source region is [0, w−1] × [0, h−1]. Pixels that land outside it get an alpha of 0, and that alpha channel is returned alongside the image so the blending step knows which pixels are real.

The source location is almost never an integer, so I implemented two ways to sample it. Nearest neighbor rounds to the closest pixel. Bilinear takes the four surrounding pixels and weights each by how close it is.

Rectification

To test the warp before building mosaics, I rectified two photos of rectangular objects taken at an angle. Since I only had one image and needed to compute the homography, I needed to define corresponding points using information I knew about the object in the image. For both the painting and computer screen, I clicked the four corners and mapped them onto a rectangle with the aspect ratios of 1100×1400 and 1600×1000 respectively. Four points give an exactly determined system, so these homographies hit the corners exactly.

Verdict

Bilinear

The extra time is small, and it removes the blocky edges, so I used it for my mosaics.

Nearest neighbor copies whole source pixels, so where the warp stretches the image, one pixel gets repeated into a visible block or diagonal edges turn into staircases. This is seen in the monitor of the computer screen image and in the borderline of the hair. Bilinear blends the four neighbors, so colors change smoothly and edges stay clean. Bilinear is slower because each output pixel reads four source pixels and does several multiplication operations instead of a single lookup. However, the gap is under a factor of 2, so I used it in my mosaics to get better quality.

Part A · 4

Blending the Images into a Mosaic

For each pair I leave image 2 unwarped and warp image 1 into its frame, then blend the two in one shot:

  1. Give each image a weight map that is highest at its center and falls off linearly to near 0 at its border, and attach it as an extra channel.
  2. Warp image 1 (with its weight channel) by H using bilinear interpolation. The corners of the warped image give its offset in image 2’s coordinates.
  3. Size the canvas to fit both the warped image 1 and image 2, and paste each into its own copy of the canvas at the right offset.
  4. At every pixel, average the two images weighted by alpha times the weight map. Where only one image exists, it is used as is.

I compare each blended mosaic against simply pasting image 2 on top of the warped image 1. The pasted version has a hard seam. The weighted average spreads that change across the overlap, so it is much harder to see.
