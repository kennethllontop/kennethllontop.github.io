Part 1

Fun with Filters

In this part, we will build intuitions about 2D convolutions and filtering. We will begin by using the humble finite difference as our filter in the x and y directions.

Part 1.1

Convolutions from Scratch!

I used NumPy to implement 2D convolutions from scratch using four for loops and two. I also made sure to flip the kernel first so the operation is actually a convolution and not a cross-correlation. 

def four_for_loops(input_img, kernal, padding):
    k_height, k_width = kernal.shape
    output = []
    flipped = np.flip(kernal)

    if padding == 'same':
        pad = ((k_height // 2, (k_height - 1) // 2),(k_width // 2, (k_width - 1) // 2))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    elif padding == 'full':
        pad = ((k_height - 1, k_height - 1),(k_width - 1, k_width - 1))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    else:
        img = np.asarray(input_img, dtype=np.float64)  # Valid Padding

    for height_idx_img in range(0, len(img)-k_height+1):
        collection_sums = []
        for width_idx_img in range(0, len(img[0])-k_width+1):
            temp_sum = 0
            for height_idx_filter in range(0, k_height):
                for width_idx_filter in range(0, k_width):
                    answer = flipped[height_idx_filter, width_idx_filter] * img[height_idx_img + height_idx_filter, width_idx_img + width_idx_filter]
                    temp_sum += answer
            collection_sums.append(temp_sum)
        output.append(collection_sums)
    return np.array(output)
def two_for_loops(input_img, kernal, padding):
    k_height, k_width = kernal.shape
    output = []
    flipped = np.flip(kernal)

    if padding == 'same':
        pad = ((k_height // 2, (k_height - 1) // 2),(k_width // 2, (k_width - 1) // 2))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    elif padding == 'full':
        pad = ((k_height - 1, k_height - 1),(k_width - 1, k_width - 1))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    else:
        img = np.asarray(input_img, dtype=np.float64)  # Valid Padding

    for height_idx_img in range(0, len(img)-k_height+1):
        collection_sums = []
        for width_idx_img in range(0, len(img[0])-k_width+1):
            # Element wise multiplication and then sum
            patch = img[height_idx_img:height_idx_img+k_height, width_idx_img:width_idx_img+k_width]
            temp_sum = np.sum(patch*flipped)
            collection_sums.append(temp_sum)
        output.append(collection_sums)
    return np.array(output)

As mentioned in the project spec, the results with just the difference operator were rather noisy. Luckily, we have a smoothing operator handy: the Gaussian filter G. We first create a blurred version of the original image by convolving with a Gaussian filter and then repeat the procedure in the previous part, but now on this blurred image. Below I show the partial derivatives, gradient magnitude image, and binarized gradient magnitude image. I used a 3×3 Gaussian kernel with σ = 0.6 to create the Gaussian filter, built with cv2.getGaussianKernel and an outer product with its transpose.

There is a notable difference in the final two images. The difference was caused by applying a Gaussian filter that reduced the noise, essentially erasing the very high frequencies. For example, there are fewer white dots in the binary edge image despite using the same threshold.

Instead of using two convolutions, we can get the result above using only one convolution. We do this by convolving the Gaussian with Dx and Dy to get the derivative of Gaussian filters, which are shown below next to the Gaussian itself.

These results should come out to be the same since convolutions are associative.

(f∗G)∗Dx=f∗(G∗Dx)=f∗DoGx(f∗G)∗Dy=f∗(G∗Dy)=f∗DoGy

To verify, I compared these results with blurring and then differentiating. Away from the border they agree up to floating-point error, and the binarized edge images are identical. The outer 2 pixels differ because the blur pads the image symmetrically while the difference operators pad with zeros. The DoG gradient magnitude image only looks brighter because each magnitude image is rescaled by its own maximum, and that maximum falls on a border pixel where the two approaches differ.

Part 2

Fun with Frequencies!

Sharpening, hybrid images, and multiresolution blending all come from separating an image into its low frequencies and its high frequencies. I will explore all three in this section.

Part 2.1

Image “Sharpening”

Deriving the Unsharp Mask

A blur filter is a low-pass filter. When we convolve an image f with a Gaussian g, what we get is a blurred image. This means we keep the image’s low frequencies and remove the high ones. Now, if we subtract the blurred image from the original, what is left is only the high frequencies, f − f ∗ g, which hold edges and other fine detail. To sharpen an image, I add those high frequencies back in, scaled by α. Not only is convolution associative, but it is also linear. This collapses the whole process into a single convolution with one filter, the unsharp mask filter, where e is the unit impulse (the identity kernel).

fsharp=f+α(f−f∗g)=f∗((1+α)e−αg)

I used a 5×5 Gaussian with σ = 0.8 and α = 4, and filtered each color channel separately.

Part 2.2

Hybrid Images

A hybrid image combines the low frequencies of one image with the high frequencies of another. Up close the high frequencies dominate and you should see mainly one image, but from far away only the low frequencies are visible, so you see the other image. In order to get the high-pass frequencies, I get one image and subtract the Gaussian blur of that image. To get the low-pass frequencies of the other image, all I need to do is apply a Gaussian filter. Lastly, to end up with the hybrid image, I just add the two.

Ihybrid=(I1−I1∗Gσ1)+I2∗Gσ2

The two σ values set the cutoff frequencies. A larger σ2 removes more detail from the low-pass image, and a smaller σ1 keeps only the finest edges of the high-pass image.

Part 2.3

Gaussian and Laplacian Stacks

A Gaussian stack repeatedly blurs the image without downsampling, so every level stays the same size. Each level blurs the previous one with σ = 2 · 2i − 1. The Laplacian stack takes the difference between neighboring Gaussian levels, so each Laplacian level holds one band of frequencies, and its last level is the blurriest Gaussian level. Adding up every Laplacian level gives back the first image in the Gaussian stack.

Li=Gi−Gi+1LN=GN

Part 2.4

Multiresolution Blending (a.k.a. the oraple!)

How do we create the oraple?!?!?! To blend two images, you can build a Laplacian stack for each image and a Gaussian stack for the mask. At each level, the mask’s Gaussian level weights the two Laplacian levels, and summing the blended levels gives the final image. Since the mask is blurred more at coarser levels, low frequencies blend over a wide transition while fine details switch over sharply, which hides the seam.

B=∑i=0N[MiLiA+(1−Mi)LiB]
