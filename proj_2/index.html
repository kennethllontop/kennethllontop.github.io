Part 1.1

Convolutions from Scratch!

I implemented 2D convolution from scratch using only NumPy, once with four for loops and once with two. Both flip the kernel first, which is what makes the operation a convolution rather than a cross-correlation. 

def four_for_loops(input_img, kernal, padding):
    k_height, k_width = kernal.shape
    output = []
    flipped = np.flip(kernal)

    if padding == 'same':
        pad = ((k_height // 2, (k_height - 1) // 2),(k_width // 2, (k_width - 1) // 2))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    elif padding == 'full':
        pad = ((k_height - 1, k_height - 1),(k_width - 1, k_width - 1))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    else:
        img = np.asarray(input_img, dtype=np.float64)  # Valid Padding

    for height_idx_img in range(0, len(img)-k_height+1):
        collection_sums = []
        for width_idx_img in range(0, len(img[0])-k_width+1):
            temp_sum = 0
            for height_idx_filter in range(0, k_height):
                for width_idx_filter in range(0, k_width):
                    answer = flipped[height_idx_filter, width_idx_filter] * img[height_idx_img + height_idx_filter, width_idx_img + width_idx_filter]
                    temp_sum += answer
            collection_sums.append(temp_sum)
        output.append(collection_sums)
    return np.array(output)
def two_for_loops(input_img, kernal, padding):
    k_height, k_width = kernal.shape
    output = []
    flipped = np.flip(kernal)

    if padding == 'same':
        pad = ((k_height // 2, (k_height - 1) // 2),(k_width // 2, (k_width - 1) // 2))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    elif padding == 'full':
        pad = ((k_height - 1, k_height - 1),(k_width - 1, k_width - 1))
        img = np.pad(np.asarray(input_img, dtype=np.float64), pad_width = pad, mode='constant', constant_values=0)
    else:
        img = np.asarray(input_img, dtype=np.float64)  # Valid Padding

    for height_idx_img in range(0, len(img)-k_height+1):
        collection_sums = []
        for width_idx_img in range(0, len(img[0])-k_width+1):
            # Element wise multiplication and then sum
            patch = img[height_idx_img:height_idx_img+k_height, width_idx_img:width_idx_img+k_width]
            temp_sum = np.sum(patch*flipped)
            collection_sums.append(temp_sum)
        output.append(collection_sums)
    return np.array(output)

Part 1.3

Derivative of Gaussian (DoG) Filter

The results with just the difference operator were rather noisy. Luckily, we have a smoothing operator handy: the Gaussian filter G. We first create a blurred version of the original image by convolving with a Gaussian and repeat the procedure in the previous part, showing the gradient magnitude images and binarized gradient magnitude image. I used a 3×3 Gaussian kernel with σ = 0.6.

The difference is that noise is minimized in a DoG filter since we blur the image, erasing the high frequencies that caused the noise.

Part 2

Fun with Frequencies!

In this part, we think about images in terms of their frequencies. Sharpening, hybrid images, and multiresolution blending all come from separating an image into its low frequencies and its high frequencies.

Part 2.1

Image “Sharpening”

Deriving the Unsharp Mask

A blur filter is a low-pass filter: convolving an image f with a Gaussian g keeps its low frequencies and removes the high ones. That means subtracting the blurred image from the original leaves only the high frequencies, f − f ∗ g, which hold the edges and fine detail. To sharpen, I add those high frequencies back in, scaled by α. Because convolution is linear, the whole process collapses into a single convolution with one filter, the unsharp mask filter, where e is the unit impulse (the identity kernel).

fsharp=f+α(f−f∗g)=f∗((1+α)e−αg)

I used a 5×5 Gaussian with σ = 0.8 and α = 4, and filtered each color channel separately.

Varying the Sharpening Amount

Increasing α adds more of the high frequencies back. Small values give a subtle boost, while large values overshoot at the edges and start to look grainy and over-processed.

Evaluation: Blur, Then Sharpen

To evaluate sharpening, I took a sharp image, blurred it with the same Gaussian, and then sharpened the blurred result with α = 4.

The re-sharpened image is much crisper than the blurred one, and the edges of the faces and hair come back. But it does not recover the original. Blurring removed the finest details, and sharpening can only amplify the high frequencies that survived the blur, not restore the ones that were lost. With α = 4 it also overshoots, so edges are harsher and the contrast is stronger than in the original.

Part 2.2

Hybrid Images

A hybrid image combines the low frequencies of one image with the high frequencies of another. Up close the high frequencies dominate and you see one image; from far away only the low frequencies are visible and you see the other. I high-pass one image by subtracting its Gaussian blur, low-pass the other with a Gaussian, and add the two.

Ihybrid=(I1−I1∗Gσ1)+I2∗Gσ2

The two σ values set the cutoff frequencies. A larger σ2 removes more detail from the low-pass image, and a smaller σ1 keeps only the finest edges of the high-pass image.

Part 2.3

Gaussian and Laplacian Stacks

A Gaussian stack repeatedly blurs the image without downsampling, so every level stays the same size. Each level blurs the previous one with σ = 2 · 2i − 1. The Laplacian stack takes the difference between neighboring Gaussian levels, so each Laplacian level holds one band of frequencies, and its last level is the blurriest Gaussian level. Adding up every Laplacian level gives back the original image.

Li=Gi−Gi+1LN=GN

Part 2.4

Multiresolution Blending (a.k.a. the oraple!)

To blend two images, I build a Laplacian stack for each image and a Gaussian stack for the mask. At each level, the mask’s Gaussian level weights the two Laplacian levels, and summing the blended levels gives the final image. Because the mask is blurred more at coarser levels, low frequencies blend over a wide transition while fine details switch over sharply, which hides the seam.

B=∑i=0N[MiLiA+(1−Mi)LiB]
